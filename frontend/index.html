🎯 系统介绍

                        
Story Agent是一个基于AI的智能故事生成器，使用OpenAI GPT模型自动创作故事，并自动保存到您的Notion数据库中。

                        
                        
✨ 主要功能

                        
    
                            
  • 🤖 AI自动生成创意故事
    • 
                            
  • 📚 多种故事类型选择
    • 
                            
  • 📏 灵活的故事长度设置
    • 
                            
  • 🔗 自动保存到Notion
    • 
                            
  • 📖 故事列表管理
    • 
                            
  • 📋 一键复制内容
    • 
                        

                        
                        
🏗️ 技术架构

                        
    
                            
  • 后端：FastAPI + Python
    • 
                            
  • AI引擎：OpenAI GPT
    • 
                            
  • 数据存储：Notion Database
    • 
                            
  • 前端：HTML + JavaScript
    •
